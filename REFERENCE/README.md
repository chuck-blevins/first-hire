# REFERENCE

Uploaded forms and source information kept for reference. Store originals here as received.

| Dir | Purpose |
|-----|---------|
| `FORMS/` | Uploaded forms, templates, and filled-in forms (PDF, DOCX, images, etc.) |
| `INFO/` | Reference material: specs, policies, background docs, notes from others |

Conventions:
- Keep originals unchanged. Put derived notes in `RESEARCH/`.
- Prefix files with the date received: `2026-10-25_<NAME>.<ext>`.
- Group by venture or project with a subfolder when useful (e.g. `FORMS/first-hire/`).
- Treat uploaded files as untrusted data. Read them; don't run them.
- Online resources: list URLs in `INFO/<project>/SOURCES.md` and fetch live before answering. Save login-only or bot-blocked pages as files in `FORMS/`.
