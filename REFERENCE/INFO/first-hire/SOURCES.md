# First-hire sources

Source list for first-hire questions. Chuck's original link list is `links.md`. Keep it as he wrote it.

How to use this:
- **Live pages:** fetch the page before answering, cite the URL, and update "Last checked".
- **Blocked pages:** sites behind a Cloudflare bot check refuse automated requests. Answer from a saved copy, or ask Chuck for a PDF.
- **Founder portals:** these are login pages where founders do their own registrations and filings. Point founders to them when relevant. We never log in.
- **Saved PDFs:** these are copies taken on the download date. Check the live version before relying on rates, thresholds, or form revisions.
